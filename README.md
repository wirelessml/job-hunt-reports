# job-hunt-reports

毎日の求人サーチ・ログ。神戸市須磨区の **戎町近辺（戎町・板宿周辺）を優先で全件**収集し、
件数が約30件に満たない場合は**リモート/在宅求人**で補完した日次レポートを保存しています。

- 生成: [job-hunt](https://github.com/wirelessml/job-hunt) の日次タスク（毎朝 04:00 JST、WSL2 + Codex CLI）
- 形式: `reports/job-report-YYYY-MM-DD.md`（求人ごとに 職種 / 媒体 / 勤務地 / 雇用形態 / 給与 / 応募先URL）
- 個人情報は含みません（求人リストのみ）。応募代行はしていません。
- 掲載内容は生成時点の確認結果です。応募前に各媒体で最新条件・募集継続を確認してください。

## 一覧

`reports/` 配下に日付順で蓄積されます。
